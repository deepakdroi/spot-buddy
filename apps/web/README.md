# Spot Buddy Web

Next.js web application with NextAuth.js authentication.

## Setup

1. Install dependencies: `npm install`
2. Configure `.env.local` with API URLs and NextAuth secrets
3. Start development server: `npm run dev`
4. Visit `http://localhost:3000`

## Features

- System-default dark/light mode with next-themes
- NextAuth.js integration with FastAPI backend
- Protected `/dashboard` route
- Login/Register pages with validation
- Navbar with theme toggle
- Responsive design with Tailwind CSS
- Muscle group performance chart with Recharts
